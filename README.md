# Aman Kumar — Java Backend Developer Portfolio

A modern, premium, recruiter-friendly personal portfolio website for **Aman Kumar**, a Java Backend Developer and B.Tech Computer Science graduate.

Built with **React + Vite + Tailwind CSS + Framer Motion + Lucide React**.

## Features

- Premium dark developer theme with emerald accent
- Fully responsive (320px → 1440px+)
- Smooth Framer Motion animations (hero entrance, scroll reveals, hover effects, timeline)
- Sticky navbar with backdrop blur, scroll-spy active link, animated mobile menu
- Animated backend-themed hero visual (orbiting tech nodes: Java, Spring Boot, REST APIs, Database, Backend)
- Categorized skill cards with animated proficiency bars
- Vertical experience timeline
- Project cards with detail modal (features, tech stack, architecture)
- Education timeline
- Certification cards
- Resume CTA section
- Contact form with frontend validation
- SEO meta tags, Open Graph, semantic HTML, accessibility attributes

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Resume

Place the resume PDF at `public/Aman_Kumar_Resume.pdf`. The download buttons reference this path. The PDF is not included in this repository — add the actual file before deploying.
